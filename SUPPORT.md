# Support

## Questions

Discussions are not enabled. To ask a question, open an [issue](https://github.com/ciranda-dev/kolo-video/issues/new/choose) and start the title with "Question:". Please read the README and the Kolo docs first, and search the existing issues.

## Bugs and feature requests

Use the issue forms: "Bug report" for something that does not work, "Feature request" for a change you would like. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to send a pull request.

## Security problems

Do not open a public issue for a security problem. Use the [private report](https://github.com/ciranda-dev/kolo-video/security/advisories/new).

## Status

kolo-video is in beta and the API may change until 1.0. Issues and questions are answered as time allows, and a response time is not guaranteed.
